
# 🛍️ Retail Chain Profit Leakage & Demand Optimization

An end-to-end retail analytics project investigating profit leakage, returns, promotions, stockout demand, vendor performance, and customer behavior.

### 🧰 Tools
**Python** · **SQL Server** · **Power BI** · **Tableau** · **Excel**

### 🔍 What I Did
- Cleaned and validated **7 retail datasets** using Excel and Python.
- Analyzed profitability, discounts, returns, promotions, inventory,customer retention, and vendor performance using SQL.
- Applied **K-Means clustering** to segment purchasing customers into 4 behavioral groups.
- Built Power BI and Tableau dashboards and automated Excel/PDF insight reports.

### 📊 Key Findings
- **₹1.46M** net profit after returns and discounts.
- **₹1.51M** return loss identified in the analysis.
- **₹42.85K** combined negative net profit across the top 5 loss-driving SKUs.
- Identified stockout hotspots, resulting in **₹3060 in estimated potential lost sales**.

*Stockout sales are estimates, not confirmed realized losses.*

### 📦 Deliverables
Python scripts and notebook · SQL analysis · Data Quality Report · Power BI dashboard · Tableau dashboard · Executive PDF and presentation

### 💡 Business Value
Translated retail data into insights to help investigate financial leakage, prioritize operational risks, and support evidence-based decisions.
